## 📌 Overview

This repository contains the source code of my personal portfolio website. It presents my background, technical skills, resume, and featured projects in a clean, single-page layout that works on desktop, tablet, and mobile.

I'm a **B.Tech (AI & Data Science)** graduate focused on the full machine learning lifecycle: data cleaning, exploratory analysis, feature engineering, model tuning, and deployment as REST API services.

> **Note:** The site is hosted on Render's free tier, so the first load after a period of inactivity may take a few seconds.

## ✨ Features

- **About** section with a summary of my focus areas and current learning path
- **Resume** section with education, certifications, skill proficiency, and a downloadable PDF
- **Filterable project gallery** (All / Machine Learning / Data Analysis / ML Web Apps)
- **Learning** section covering LLMs, Agentic AI, MLOps, Docker, and Cloud Deployment
- **Contact** section with an embedded map and message form
- Fully **responsive** design with SEO and social-sharing (Open Graph / Twitter Card) meta tags

## ⚙️ Run Locally

No build step is required.

```bash
# 1. Clone the repository
git clone https://github.com/Sahilattar/Portfolio.git

# 2. Move into the project folder
cd Portfolio

# 3. Open index.html in your browser
#    or serve it locally (recommended):
python -m http.server 8000
```

Then visit **http://localhost:8000** in your browser.
